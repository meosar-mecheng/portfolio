# Mehmet Osar — Engineering Portfolio (near-final version)

A complete static HTML/CSS/JavaScript website for VS Code and GitHub Pages. No build system or paid hosting required.

## Open and preview

1. Unzip the website and open the folder in VS Code.
2. Install the **Live Server** extension and choose **Open with Live Server** on `index.html`.
3. Navigate through four project cards and review all photos, charts, videos, and the embedded resume.

## Edit your content

- `index.html` — homepage, introduction, About, Experience, headings and links.
- `assets/projects.js` — all four project pages, titles, sections, quantitative results and media captions.
- `assets/styles.css` — appearance, typography, responsive layout.
- `assets/site.js` — email, LinkedIn and resume path (already populated).
- `assets/images/` — uploaded project images.
- `assets/videos/` — H-arm SuspensionSim and Baja CarSim recordings. Keep the filenames when replacing.
- `FINAL_CHECKLIST.md` — final review, sharing permissions, and optional improvements.

### Resume

The resume PDF is already saved as `assets/Mehmet_Osar_Resume.pdf`. The homepage includes both an Open PDF link and a full-page embedded preview near the bottom. Preview works best when running through Live Server (rather than opening the file directly).

### Publishing through GitHub Pages

1. Create a public GitHub repository named `YOURUSERNAME.github.io`, replacing the username.
2. Upload the **contents** of this portfolio folder (including the `assets` folder) to the repository root.
3. Go to Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Open `https://YOURUSERNAME.github.io` after deployment.

If you have already edited your `index.html` or `assets/projects.js`, keep a copy and merge them carefully to preserve your changes.
